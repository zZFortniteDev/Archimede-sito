# 🛠️ Archi For All | IS Archimede - Sito Ufficiale (Coming Soon)

Sito web moderno e responsive per la lista di rappresentanza studentesca **`lista.archimedeforall`** dell'IS Archimede.

## ✨ Caratteristiche

- **Design Dark OLED Futuristico**: Sfondo nero profondo (`#06070b`) con sfumature luminose e mesh di particelle interattive al 100% in HTML5 Canvas.
- **Micro-interazioni & Animazioni Fluide**:
  - Badge *"Coming Soon"* pulsante con onda radar.
  - Ticker/Marquee scorrevole orizzontale infinito.
  - Card 3D tilt con effetto vetro (glassmorphism) e neon glow reattivo al movimento del mouse.
- **Integrazione Instagram `@lista.archimedeforall`**:
  - Profilo in evidenza con badge di verifica e gradiente ufficiale Instagram.
  - Pulsante ad apertura diretta con icona.
  - Tasto **"Copia @tag"** con notifica a comparsa (Toast).
  - Strumento interattivo **"Segnala un problema in DM"**: genera automaticamente un messaggio pre-compilato con classe e categoria e apre i Direct Messages (`https://ig.me/m/lista.archimedeforall`).
- **Zero-Dependency**: Nessun framework pesante o build step richiesto. Funziona immediatamente su qualsiasi dispositivo e browser.

## 🚀 Come visualizzarlo subito

Fai semplicemente doppio click sul file `index.html` all'interno della cartella:
```
C:\Users\paper\.gemini\antigravity\scratch\archimede-for-all-site\index.html
```
Oppure avvia un server locale con Python o Node:
```powershell
# Esempio con Python:
python -m http.server 3000

# Poi apri nel browser: http://localhost:3000
```

## 🌐 Come pubblicarlo online gratuitamente

Puoi pubblicarlo in 2 minuti su:
1. **GitHub Pages**: Carica questi file su un repository GitHub e attiva GitHub Pages da *Settings > Pages*.
2. **Vercel / Netlify**: Trascina l'intera cartella `archimede-for-all-site` sulla dashboard di Vercel o Netlify per avere un link istantaneo (es. `archiforall.vercel.app`) da incollare direttamente nella bio di Instagram!
